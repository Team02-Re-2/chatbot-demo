# 팀2 챗봇 진행 현황 (공개 시연용)

쇼핑 상담 챗봇 프로젝트의 진행 요약과 시연 화면입니다. 원본 데이터와 팀 문서는 들어 있지 않습니다.

- `index.html`: 진행 요약
- `stage-demo/`: 단계 인지형 답변 추천 시연판
- `handoff/`: 상담 이관 챗봇 목업. 고객 모드(`#customer`), 관리자 모드(`#admin`), 나란히 보기(`#both`). 키워드 규칙 판정만 들어 있고, 대화는 여는 사람의 브라우저에만 저장됩니다.

데이터 출처: AI 허브 「민원(콜센터) 질의-응답 데이터」. 시험 문장은 모두 지어낸 문장입니다.
