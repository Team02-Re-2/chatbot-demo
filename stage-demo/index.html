      근거로 쓴 매뉴얼 항목

      공유용 판입니다. 로컬판은 임베딩 모델과 벡터 DB(Chroma)로 의미 검색(밀집 벡터)을 하지만, 이 화면은 바깥 API 호출이 막혀 있어 단어·글자 기반 희소 검색(BM25, TF-IDF)과 보는 사람의 Claude를 씁니다. 가상 고객과 조회 정보는 꾸며 낸 것입니다. 전화번호·카드번호 형식은 보내기 전에 가리지만 이름과 주소는 가리지 못하니 실제 고객 정보는 넣지 마세요. 매뉴얼은 회사 승인 규정이 아닌 프로젝트 기준안입니다.

      질문 하나를 넣으면 모델 호출 없이 검색 단계만 돌려 봅니다. BM25, TF-IDF, 둘을 합친 RRF 순위와 임계값 판정, 모델에 보낼 프롬프트까지 확인합니다.
