고객 화면 + 상담사 화면
(관리자 대시보드)
  1. 0:00첫 화면 숫자 설명
  2. 0:15먼저 묻기: 불만 점수 0.79 → 0.97, 연결 여부 질문
  3. 0:45"네" → 상담사 화면 대기 1건, 인계 정보 확인
  4. 1:10새 상담: 모델 0.00이어도 안전장치 규칙이 잡음
  5. 1:40상담 시작 → 처리 완료 → 발표 화면 복귀
시연 전 확인: 공개 사이트는 규칙 + 팀 모델 v2로 판정하고, Claude 판정은 클로드 챗봇(만든 계정으로 로그인)에서만 동작합니다. 아래 점수는 공개 사이트에서 직접 넣어 확인한 값입니다 (11/26).

대본: 말할 것 · 누를 것

"지금 보시는 게 저희 시제품입니다. 왼쪽은 고객이 보는 챗봇, 오른쪽은 상담사가 보는 관리자 화면입니다. 위 숫자처럼 기준선 0.7로 상담사 연결을 22.2%에서 10.9%로 줄인 판정이 이 챗봇 안에서 그대로 돌아갑니다."

누르기 · 확인
  1. 첫 화면 맨 위 숫자 3개를 손으로 가리킵니다.
  2. 챗봇 위 파란 점 "팀 모델 v2 + 규칙 안전장치로 판정 중"을 확인합니다.

누르기 · 확인
  1. 시연 문장 ① 먼저 묻기 → 관리자 화면 판정 불만 0.79
  2. ② 먼저 묻기 → 불만 0.97, 챗봇에 연결 승인 카드

누르기 · 확인

  2. 관리자 화면 대기 1, 누적 이관 건이 맨 위에
  3. 오른쪽 인계 정보의 이관 발화 · 판정 이력 · v2 점수를 가리킵니다.

누르기 · 확인

  2. Alt+Tab으로 발표 화면 복귀

시연 전 · 질문 대비

발표 전 (15분 전)

  • 발표 준비 화면에서 "지금 모두 받아 두기" (팀 모델 약 220MB, 처음 한 번)
  • 관리자 화면 기록 지우기 → 대기 0에서 시작
  • 첫 화면을 열어 두고 새로고침하지 않기. 노트북이 작으면 F11
  • 챗봇 위 점이 파란색(v2)인지 확인. 회색이면 규칙만으로 판정 중
시연 화면 열기 발표 준비

시간이 남거나 질문이 나오면

  • 즉시 "진짜 미친 거 아니에요? 2주째 안 오잖아요" → 즉시 이관
  • 맥락 "주문 취소해 주세요" → 빠른 답 버튼만 차례로: 배송완료 주문이라 취소가 반품으로 바뀌고 접수 카드 → 이관 없이 챗봇이 해결
  • 먼저 묻기에서 아니요를 누르면 챗봇이 계속 응대합니다. 그 뒤 불만이 또 나오면 바로 연결돼요
  • Claude 판정 비교는 클로드 챗봇 (만든 계정으로 로그인)
