발표 준비: 시연 전에 이 화면만 보면 돼요

발표에 쓸 노트북·브라우저로 여세요. 이 브라우저 안에서만 확인하고, 서버로 보내는 것은 없어요. 숫자는 바꾸지 않아요.

확인 중

1. 자동 확인

2. 팀 모델 미리 받아 두기

팀 모델(약 220MB)을 이 브라우저 저장소에 넣어 둬요. 다 받은 뒤에는 발표장 인터넷이 느리거나 끊겨도 챗봇이 저장본으로 열려요. 집이나 학원 와이파이에서 미리 해 두세요.

3. 사람이 확인할 것

자동으로 못 보는 것들이에요. 체크는 이 브라우저에만 남아요.

4. 시연 순서 메모

  1. 즉시 이관: "진짜 미친 거 아니에요? 2주째 안 오잖아요"
  2. 안전장치: "팀장님 바꿔 주세요"
  3. 먼저 묻기: 시연 문장의 ①, ②, ③을 순서대로
  4. 맥락 이어 가기: 시연 문장 "맥락"을 누른 뒤 아래 빠른 답 버튼만 차례로 (김민지 번호 → 네, 맞아요 → 네, 진행해 주세요 → 디자인이 마음에 안 들어요 → 네, 진행해 주세요 → 없어요, 감사합니다). 취소가 반품으로 바뀌고 접수 카드가 떠요.
  5. 먼저 묻기에서 [아니요]를 누른 뒤에는 평범한 질문을 치지 마세요. 앞 대화 때문에 바로 이관될 수 있어요 (원본 엔진의 동작).
