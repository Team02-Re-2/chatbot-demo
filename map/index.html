7. 챗봇 한 턴

sequenceDiagram
  actor 고객
  participant 챗봇
  participant v2 as 팀 모델 v2
  participant 규칙 as 규칙 안전장치
  participant 상담사
  고객->>챗봇: "왜 이렇게 늦는지 답답하네요"
  챗봇->>v2: 고객 말 + 앞 문맥 4개
  v2-->>챗봇: 불만 점수 · 즉시 이관 점수
  챗봇->>규칙: 욕설 · 신고 · 책임자 요구?
  규칙-->>챗봇: 해당 없음
  alt 즉시 이관 {{th_c}} 이상 또는 규칙 해당
    챗봇->>상담사: 바로 연결 + 인계 카드
  else 최근 3개 중 2개 불만
    챗봇->>고객: 상담사에게 연결해 드릴까요?
  else 그 밖
    챗봇->>고객: 매뉴얼 근거 답변
  end
